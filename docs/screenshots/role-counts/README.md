# Big Board role counts

Captured from the running app at 1440 × 1000 (desktop) and 400 × 1000 (phone),
in light and dark mode. All players, clubs, placements, ranks and stars are
synthetic; no real club scouting data is shown.

The examples show 30/20 and 21/20 shaded red, with 10/20, 20/20 and 0/20 neutral.
Browser checks also confirmed that Short Board and NCAA counts are unchanged.
