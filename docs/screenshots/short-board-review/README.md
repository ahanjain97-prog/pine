# Short Board review flag

Captured from the running app at 1440 × 1000 (desktop) and 400 × 1000 (phone),
in light and dark mode. All players, clubs, board placements and review events
are synthetic; no real club scouting data is shown.

- The 16-day-old target is flagged on the Short Board in both roles, while the
  same player is unflagged on the Big Board.
- The 13-day-old target is unflagged on both views.
- The 14-day-old target uses the PINE creation-date fallback and is flagged only
  on the Short Board.
- The 28-day-old target is flagged on both views.
- The Key explains the 14-day threshold; the Big Board Key still says 28 days.

Browser checks verified that Mark reviewed clears every role and both views,
that the NCAA view stays unchanged, and that tags and review ages remain visible
at both widths in both themes, with no card overflow or JavaScript errors.
