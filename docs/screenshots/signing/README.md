# Signed player screenshots

These screenshots show the running app with synthetic players, decisions and board rankings.
They contain no real club scouting data. `overview.jpg` compares the player page, Big Board,
Short Board, NCAA board, player list and search.

Desktop captures use 1280 × 720; phone captures use 400 × 900. Light and dark captures use
the app's existing theme rules. The dark captures apply its dark media-query rules through
a local QA proxy without changing system preferences.
