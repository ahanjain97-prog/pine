# Short Board role counts

Captured from the running app at 1440 × 1000 (desktop) and 400 × 1000 (phone),
in light and dark mode. All players, clubs, placements, ranks and stars are
synthetic; no real club scouting data is shown.

The examples show 6/5 shaded red, with 3/5, 5/5, 1/5 and 0/5 neutral. Browser
checks also verified that unstarring the sixth target changes the count to 5/5
and clears the highlight; starring the player again restores red 6/5.
Big Board counts retain N/20 and their existing threshold. NCAA counts are unchanged.
